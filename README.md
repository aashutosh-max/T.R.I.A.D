# T.R.I.A.D
**Three Rods Interface Analysis & Disruption**

A custom portable cyberdeck designed for penetration testing and network disruption. 

## Features
- Triple-screen setup (Main terminal, virtual keyboard, system stats)
- Physical jumper-wire mode switching (WiFi, Bluetooth, GSM, TRS, FM)
- External disruption rods for Bluetooth and IR
- Custom PCB and battery UPS system

## Hardware Stack
- Raspberry Pi 5 (8GB)
- Parrot OS (booted from USB flash drive)
- Custom PCB (in development)
